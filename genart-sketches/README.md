# GenArt Sketches Collection

This is your main audio-responsive visualization collection with 20+ different sketches.

## Features

- **Audio Analysis**: Tone.js-based analysis with bass, mid, high frequencies
- **Multiple Sketches**: 20+ different visualization styles
- **Real-time Performance**: Optimized canvas rendering

## Sketches Included

### Audio-Responsive
- Rhythm Grid
- Timbre Spectrum
- Long Exposure Beams (v1, v2, v3)
- Neon Painter

### Light Trails
- Light Highway
- Chromatic Flow

### Geometric Patterns
- Spiral Galaxy
- Fractal Tree
- Chromatic Kaleidoscope

### Attractors & Particles
- Lorenz Attractor (v1, v2, v3)
- Rössler Attractor (v1, v3)
- Particle Field (v1, v2, v3)
- Audio Waveform (v1, v3)

## How to Run

From the GenArt2025 directory:
```
npm run dev
```

Then open: `http://localhost:5173/genart-sketches/`

## Files

- `index.html` - Main HTML page
- `main.js` - Application entry point
- `sketches/` - All visualization modules
- `aestheticSystem-v3.js` - Aesthetic color system
- `colorPalette.js` - Color palette definitions
